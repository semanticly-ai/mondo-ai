# mondo-ai

AI-powered tools for Mondo disease ontology curation and quality assurance.

## Installation

```bash
pip install mondo-ai
```

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/monarch-initiative/mondo-ai.git
cd mondo-ai
```

2. Initialize the project:
```bash
just setup
```

3. Run tests:
```bash
just test
```

4. Run linting:
```bash
just lint
```
